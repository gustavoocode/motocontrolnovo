# MotoControl, etapa 1

Base do app (PWA), armazenamento no aparelho, backup e layout com menu.

    npm install
    npm run dev        # testar no computador
    npm run build      # gera a pasta dist/ para publicar

Publique a pasta `dist/` no Netlify (arrastar e soltar) ou no GitHub Pages.
No iPhone: abra o endereço no Safari, toque em Compartilhar e em "Adicionar à Tela de Início".
